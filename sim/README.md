# 豊穣の水田 v0.1（水系リデザイン）— ルールエンジンと自己対戦シミュレーター

今の `online/` とは別系統の、作り直し版の検証用コード。UI はなく、ルールの計算とボット同士の自己対戦だけを行う。
**AIは使っていない（Node.js だけで動く）ので、手元のPCで何局回しても無料。**

## 動かし方（Windows / Mac 共通）
Node.js 18 以上が入っていれば、インストール作業は不要。

```bash
cd sim
node test.mjs                          # 計算の正しさの確認（本体と高速版の突き合わせ3000盤面＋手計算例）
node sweep.mjs configs/default.json    # 既定ルールで48局（4種のボット×全席順×2局）
node sweep.mjs configs/upstream_test.json
node diag_seat.mjs "{\"label\":\"席順\",\"games\":100,\"params\":{}}"   # 全員同じボットで席の有利不利だけを見る
```

数値を変えて試すときは `configs/` にJSONを作り、`params` に `engine.mjs` の `DEFAULT_PARAMS` の項目を書く（例：`{"label":"雨多め","gpp":2,"params":{"rainBase":[5,7,5]}}`）。
48局でだいたい1〜2分。勝率は48局だと±7ポイントほど揺れるので、判断には `gpp` を増やす。

### 出力の読み方
| 項目 | 意味 |
|---|---|
| `win` / `score` | 勝ち筋（ボット）ごとの勝率・平均点。`greedy`=方針なしの貪欲ボット |
| `seat` | 席ごとの勝率（理想は全員 0.25 前後） |
| `act` | 全行動に占める割合。`labor`（日雇い）が多い＝やることがないサイン |
| `yieldPos` / `defPos` | 上流・中流・下流の田の、1回の収穫あたり平均収量・水不足 |
| `variety` | 植えられた品種の割合（0 に近い品種は死に手） |
| `struct` | 勝ち筋ごとの田の数(f)・水路の長さ(c)・溜池(r)・堰(w) |

## ルール v0.1（要約）
- 中央の水源から人数ぶんの川。各川に上流・中流・下流の節、各節に区画3つ。各自は自分の川の下流に田2枚で開始
- 1年＝春・夏・秋（配置→水の流れ→収穫）＋冬（維持費→献上）。5年
- 働き手2人を、1枠1人の行動に交互に置く。枠は人数−1（溜池・堰は1）
  - 開墾（上3/中2/下1俵）・水路（上流の節から水を取る、長さ×2俵）・植付（田4枚まで）・手入れ（田3枚まで今年の収量+1）・溜池（4俵）・堰（6俵）・日雇い（+1俵、枠なし）
- 水の流れ：降水を川ごとに均等 → 上流の節から順に、その節で取る田（その節の田→水路で引いている田）が必要量まで取る → 余りは末端の溜池へ
- 収量＝地力（上4/中5/下6）− 不足した水 ＋ 品種補正 ＋ 手入れ
- 品種（春・夏・秋の必要水量／補正）：早稲 2・1・− ／0、中稲 1・3・1 ／+1、晩稲 −・2・3 ／+1（台風30%で−3）
- 冬：働き手1人1俵＋上流の田1枚1俵。献上1俵＝1点。終了時：献上＋景色（田1・水路の長さ1・溜池2・堰2）＋残り米3俵で1点
- 手番順：米＋献上の合計が少ない人から（`orderMode: 'lowest'`）

## シミュレーションで分かったこと（2026-10-05 時点）

| # | 発見 | 対応 |
|---|---|---|
| 1 | 取水口を所有制にすると、上流を開墾してもその節の取水口を他人に取られて**水が来ない死に田**ができる | v0.1 で取水口を廃止。田は自分の節で取り、水路は上流から取る権利に |
| 2 | 植付が「1枠で2枚」だと全員合わせて年12枚ほどしか植えられず、**土地を広げる意味がない**。働き手の約7割が日雇いになっていた | 植付4枚・働き手2人・手入れ追加で、日雇いは約26%まで減った |
| 3 | 献上はいつ出しても1俵＝1点なので、**最終年まで溜めるのが常に最善**。「投資か献上か」のジレンマは成立していない | 未解決。年ごとの上限（`offerCapPerYear`）や、年ごとの順位報酬などの案を試す |
| 4 | 季節ごとに先手をずらす方式だと、1年3季節・4人で周期がずれ、**特定の席が勝率5〜15%**まで沈む。年ごとにずらすとさらに悪化（63%対3%） | 「合計が少ない人から」に変更。100局で 36/24/16/24% ほど。まだ合格条件（差5ポイント以内）は満たしていない |
| 5 | 早稲はほぼ植えられない（0〜3%）。水を厳しくすると20%まで増える | 夏の水不足が早稲の存在理由なので、降水量と合わせて調整 |
| 6 | 勝ち筋の勝率（既定、48局）：貪欲38%・下流33%・上流17%・水路網13%。水を厳しくすると上流23%・下流24%・水路網8% | 水路網が最弱。水路が高い（長さ×2俵）か、景色点が安すぎる可能性 |

### 注意（忖度なし）
- ボットは「典型的な1年の収量の増分×残り年数」で判断する単純な先読みで、人間の上級者よりは弱い。**ボットの下手さを、戦略の弱さと取り違える危険**がある（v0では上流ボットが、植えられない田を買い続けていた）
- 勝率は48局だと±7ポイント程度の誤差がある

- `run.mjs` / `sweep.mjs` / `diag_seat.mjs` … 自己対戦と集計
